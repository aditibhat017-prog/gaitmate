Technology

GaitMate explores a wearable approach to monitoring ankle rehabilitation using localized sensor patches, movement analysis, and digital feedback.

Wearable Sensor System

The proposed system uses sensor patches positioned around the lateral ankle to capture localized mechanical changes during movement.

Patch Architecture

Each wearable patch is being designed as a layered system combining skin-safe adhesion, a sensing layer, and a protective outer layer.

Data Analysis

Sensor measurements can be processed to characterize movement patterns and explore changes throughout rehabilitation.

Digital Platform

GaitMate's proposed digital interface is designed to translate sensor measurements into understandable feedback for patients while providing clinicians with longitudinal rehabilitation data.
